# Reference Spectra for radpair Tests

This directory contains 7 pre-computed cw-EPR spectra of singlet-born
spin-correlated radical pairs, generated by
`tests/generate_reference_spectra.py`.  Each spectrum is stored as an
`.npz` file containing the field axis (`B_z`), the intensity array, and
all input parameters as metadata.

## Common Parameters

| Parameter | Value |
|-----------|-------|
| Microwave frequency | 9.75 GHz (X-band) |
| Field axis | 500 points, 344–350 mT |
| Grid points | 12 |
| Refinement | 1 (no interpolation) |
| CPU cores | 1 (deterministic, single-core) |

|-----------|-------|
| g1 | [2.0023, 2.0040, 2.0060] (anisotropic) |
| g2 | [2.0080, 2.0100, 2.0120] (anisotropic) |

| donor / acceptor | [] / [] |
| width | 0.05 mT |

**Covers:** 0 nuclei, anisotropic g1+g2, nonzero D/E/J, nonzero frames.

### S2 — 1 nucleus (donor ¹H), isotropic baseline

### S4 — Swap of S3 (1 acceptor ¹H + 1 donor 2×¹⁴N)

Identical to S3 except `donor_list=[2]`, `acceptor_list=[1]` — nuclei
swapped between radicals.

**Covers:** donor/acceptor swap, verifies assignment-dependent code paths
(MHz→T conversion uses different g-tensor, sign flip in diff_hyperfine).

## Notes

- Pure acceptor-only assignment (all nuclei on acceptor, none on donor)
  is not covered by a dedicated spectrum.  The swap pair S3↔S4 exercises
  the acceptor code path, so the mechanism is tested.
- S3 and S4 have similar spectral sums (as expected for a donor/acceptor
  swap of the same nuclei).
- All spectra exhibit both positive and negative intensities, the
  hallmark of spin-correlated radical pairs.
